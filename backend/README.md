# Backend starter
Run `npm install`, copy `.env.example` to `.env`, set `MONGODB_URI`, then run `npm run dev`.

Endpoints:
- `GET /api/health`
- `GET /api/products?q=watch&category=Electronics`
- `GET /api/products/:id`

This is a starter API, not production-ready. Authentication, orders, payment verification, and admin authorization are not included yet.
